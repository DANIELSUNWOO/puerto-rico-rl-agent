# 실험 8: 더 길게 학습하기 (2026-11-11)

## 목적

- 실험 5·6에서 600만 스텝까지 계속 강해졌고 포화가 보이지 않았음. Moka v3(E6_60)에서 같은 구성으로 600만 스텝을 더 학습하면 또 강해지는지 확인.
- 바꾸는 건 학습량 하나. 상대 구성, 학습률은 실험 6과 같음.

## 설계

- 출발점: E6_60 (Moka v3)
- 상대 구성: 실험 6과 같음 (자기 자신 20%, SearchLite 10%, 원본 5%, E3_10 5%, E3_20 10%, E3_30 10%, TradeBuilding 15%, ActionValue 15%, Factory 5%, ShippingRush 5%)
- 학습률 0.00001에서 다시 시작(끝에 0까지 줄어듦), 600만 스텝, 100만마다 체크포인트 (E8_10 ~ E8_60)

명령:

```
python training/train_moka.py --num_players 2 --init_ckpt results/exp06_searchlite/checkpoints/ckpt_final.pt --pool_ckpts e3_10=...,e3_20=...,e3_30=... --opponents self:0.2,searchlite:0.1,orig:0.05,e3_10:0.05,e3_20:0.1,e3_30:0.1,tradebuilding:0.15,actionvalue:0.15,factory:0.05,shippingrush:0.05 --lr 1e-5 --total_timesteps 6000000 --ckpt_interval 1000000 --eval_interval 1000000000 --out_dir results/exp08_longer
```

실험 7(공격수)이 끝나자마자 `;`로 이어서 시작함.

## 학습

- 2026-11-11 06:04쯤 ~ 16:45쯤, 10.67시간 (실험 6은 11.96시간), 초당 약 156~174스텝. 에러 없음.

- 실험 5, 6과 달리 학습 중 숫자가 거의 그대로임. 원본, SearchLite, 기본 봇 상대는 이미 85~99%라 더 오를 자리가 거의 없음. 과거 체크포인트(E3_30) 상대만 73% → 80%로 조금 오름.
- 그래서 학습 중 숫자로는 강해졌는지 판단할 수 없음. 지금 연습 상대들이 Moka에게 너무 쉬워져서, 더 배울 게 적은 상태일 수도 있음. 판정은 리그전으로.
- 이 결과는 연습 상대를 바꿔야 한다는 근거도 됨: 과거의 나를 최신 체크포인트로 바꾸고, 실험 7의 공격수처럼 Moka를 실제로 이기는 상대를 넣는 쪽.
