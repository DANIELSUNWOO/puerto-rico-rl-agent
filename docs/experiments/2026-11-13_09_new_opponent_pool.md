해석 (학습 중 숫자, 판정은 리그전으로):

- 학습하는 쪽은 sampled라 같은 실력이면 40% 안팎이 기준.
- 9a는 어려운 상대들 상대로 숫자가 꾸준히 오름. 출발점 Moka v4 상대 42% → 62%, 공격수 상대 31% → 46~50%, Moka v3 상대 50% → 71%. 실험 8과 달리 배우는 게 숫자로 보임.
- 공격수 상대 100만 지점 31%는, 실험 7의 공격수가 Moka v4에게도 꽤 통한다는 뜻이었음. 그게 같은 실력 기준(40%)을 넘어서 구멍이 메워지는 모습.

- 9b는 실험 8처럼 거의 평평함 (모두 이미 75~100%). 예상대로.
- 주의: 9a는 공격수를 연습 상대로 직접 썼으므로, 리그전에서 9a가 X7_60을 이겨도 "구멍이 메워졌다"는 증거로는 약함. 9a를 새로 노리는 공격수(실험 10)로 따로 확인해야 함.
