## 채택 기준

2026-11-14에 바꿈. 약한 상대를 100% 이기는 것보다, 강하고 복잡한 상대를 이기는 게 무패 우승에 중요하다는 판단 (실제 리그전 상대는 기본 봇처럼 단순하지 않고 공들여 학습한 에이전트일 것이므로). 목표는 모든 상대에게 골고루 80% 이상.

1. 직전 최고 에이전트와의 직접 대결에서 50%를 확실히 넘음 (처음 보는 1000판, 95% 범위 아래 끝이 50% 위)
2. 모든 상대에게 80% 이상. 그중 강하고 복잡한 상대(탐색 봇, 우리 계열 최강, 공격수)에서 떨어지지 않을 것. 이미 90% 넘게 이기는 단순한 상대는 90% 이상만 지키면 하락을 문제 삼지 않음
3. 시간 초과, 불법 행동 0

버전을 비교할 때는 "가장 낮은 상대 승률"을 먼저 봄.

이전 기준 (2026-11-13까지): 2번이 "baseline 상대 승률이 의미 있게 떨어지지 않음"이었음.
