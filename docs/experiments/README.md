## 측정 기준

- 도구: tools/course_ladder.py (같은 시드를 좌석 바꿔 두 번, 격리된 프로세스, 동시 실행)
- 참가자 폴더: results/entries/ (버전마다 학번_이름 폴더)
- 실험마다 비교: 시드 10000-10099 (상대마다 200판). 상대는 원본 PPO와 baseline 8종
- 좋은 후보 최종 확인: 시드 20000번대 (자주 쓰지 않음)
- 중요한 최종 판단: 한 번도 안 쓴 번호대 (예: 30000)

## 채택 기준

1. 직전 최고 에이전트(처음엔 원본 PPO, 지금은 Moka v4)와의 직접 대결에서 50%를 확실히 넘음 (1000판 95% 범위 아래 끝이 50% 위)
2. baseline 상대 승률이 의미 있게 떨어지지 않음 (200판 흔들림 안의 1~2판 차이는 하락으로 보지 않음)
3. 시간 초과, 불법 행동 0
