# 실험 14: 학습 길이만 바꾸기 (6M vs 12M) / 새 시험용 대역 P6 (2026-11-21 ~ 11-23)

## 목적

- 실험 13에서 P5(조교 체크포인트, 자기 대국, 1200만 스텝)가 P4(600만 스텝)보다 훨씬 강했음 (참가자끼리 46.4% vs 24.2%). 학생 대역끼리 가장 큰 차이는 학습 길이.
- 그래서 Moka도 학습 길이만 바꿔 봄. 14a(600만)와 14b(1200만)는 출발점, 상대 구성, 학습률, 시드가 모두 같고 스텝 수만 다름.
- P5까지 연습 상대로 쓰므로, 한 번도 연습하지 않은 새 시험용 대역 P6를 만듦.

## 설계

- 출발점 Moka v7 (E13a_60), 학습률 0.00001(끝에 0까지), 시드 42.
- 14a: 600만 스텝. 14b: 1200만 스텝. 나머지는 같음.
- 상대 구성 (14a, 14b 같음):

| 상대 | 비율 |
|---|---|
| 자기 자신 | 35% |
| P5 / P4 / P1 / P3 / P2 | 10 / 6 / 5 / 4 / 3% |
| Moka v7 / 12c / Moka v6 / 13b | 5 / 4 / 3 / 2% |
| SearchLite | 5% |
| TradeBuilding / ActionValue | 6 / 6% |
| Factory / ShippingRush / 원본 | 2 / 1 / 3% |

- 실험 13과 달라진 점: P5를 연습 상대에 넣음(가장 강한 대역이라 10%). 실험 13에서 효과가 없던 Search·MCTS는 뺌.
- P6: 조교 체크포인트에서 자기 대국 100%, 학습률 0.00001, 시드 23, 1200만 스텝.
- 순서: 14a → 14b → P6를 `;`로 이어서. 화면 출력은 Tee-Object로 console.txt에 남김.
