# 실험 4: 더 오래 학습하기 / 과거의 나와 연습하기 (2026-11-08)

## 목적

- 실험 3에서 E3_25 → E3_30에도 크게 올라서 학습이 아직 포화되지 않았음. 더 학습하면 더 강해지는지 확인.
- 다른 학생들은 대부분 조교 체크포인트에서 조금씩 개선한 에이전트일 것. 그런 상대와 비슷한 우리 과거 체크포인트(E3_10, E3_20)와 연습하면 도움이 되는지 확인.

## 설계

두 가지를 한 번에 바꾸면 무엇 때문에 좋아졌는지 알 수 없어서, 출발점과 학습량은 같게 하고 상대 구성만 다르게 두 번 학습함.

| | 실험 4a: 더 오래 | 실험 4b: 과거의 나 추가 |
|---|---|---|
| 출발점 | E3_30 (Moka v1) | E3_30 (Moka v1) |
| 학습량 | +300만 스텝 | +300만 스텝 |
| 학습률 | 0.00001 | 0.00001 |
| 상대 | 실험 3과 같음 | 실험 3 구성 + E3_10, E3_20, E3_30(고정) |
| 체크포인트 | 100만 스텝마다 (3개) | 100만 스텝마다 (3개) |

실험 4b 상대 비율:

| 상대 | 실험 3 / 4a | 실험 4b | 이유 |
|---|---|---|---|
| 자기 자신 | 40% | 30% | 과거의 나에게 일부 양보 |
| 원본 | 10% | 5% | 이미 77%로 이기니 줄임 |
| E3_10 (고정) | - | 5% | 원본보다 조금 강한 학생 수준 |
| E3_20 (고정) | - | 10% | 원본보다 꽤 강한 학생 수준 |
| E3_30 (고정) | - | 10% | 출발점 자신. 원래 실력을 잊지 않게 |
| TradeBuilding | 15% | 15% | 그대로 |
| ActionValue | 15% | 15% | 그대로 |
| Factory | 10% | 5% | 이미 100%라 줄임 |
| ShippingRush | 10% | 5% | 이미 99.5%라 줄임 |

- 판단 기준: 4a가 E3_30보다 강하면 "더 오래 학습"의 효과, 4b가 4a보다 강하면 "과거의 나와 연습"의 효과.

## 학습 코드 수정

- train_moka.py에 --pool_ckpts 옵션 추가. "이름=체크포인트 경로"로 과거 체크포인트를 등록하면 --opponents 비율에 그 이름을 쓸 수 있음.
- 신경망 상대(원본, 과거 체크포인트)는 한 번만 불러와서 재사용. 원래는 게임마다 파일을 새로 읽어서 시간이 낭비됐음.

## 시운전

- E3_30에서 다시 학습률 0.00001로 시작해도 첫 kl이 0.0128로 적정 범위. 실험 3 시작(0.0119)과 비슷함.
- 상대 9종이 비율대로 섞이고, 과거 체크포인트 상대별 승률도 나옴.

## 본 학습

- 4a: 1.63시간, 초당 약 514스텝
- 4b: 1.76시간, 초당 약 476스텝

- 실험 3 본 학습은 초당 약 410스텝이었는데, 이번엔 4a 514, 4b 476. 실험 3은 배터리 모드였을 가능성이 있고, 오늘은 충전기 + "최고의 성능" 설정. 전원 설정이 학습 속도에 20% 넘게 영향을 줌.
- 4b가 4a보다 조금 느린 건 신경망 상대(과거 체크포인트)가 늘어서 상대 쪽 계산이 더해졌기 때문으로 보임.
- 둘 다 kl이 0.013 근처에서 시작해 0까지 매끄럽게 내려감. 튀는 구간 없음.
