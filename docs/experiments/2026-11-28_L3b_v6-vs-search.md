# 래더에 실제로 낸 v6와 탐색 버전 직접 비교 (2026-11-28)

## 목적

- 래더 3에는 실수로 이전 버전을 냈음 (내 확인, 11/28). 래더 2와 3은 상대 전적이 소수점까지 같은 상대가 넷이라 (L3 문서) 래더 2도 같은 파일이었을 가능성이 큼. 그러면 실제 래더에서 결과가 나온 것은 v6 하나뿐이고, v7·v8·탐색 버전의 이득은 모두 노트북 측정.
- 그런데 탐색 버전(MokaS)과 v6를 직접 잰 적이 없음. 지금까지는 v7이 v6를 63.4% (실험 13), MokaS가 v7을 73~76%로 이긴다는 것을 이어 붙여 짐작했을 뿐.
- 래더 4(MokaS) 결과를 래더 3(v6)과 상대별로 비교하기 전에, 노트북에서 둘의 차이를 직접 재 둠.

## 설계

- 엔트리 (results/entries_v6chk):
  - Moka6: 래더 1에 낸 v6. 가중치는 results/exp12b_proxies/checkpoints/ckpt_final.pt를 export_entry.py로 꺼낸 것이고, SHA256 7872144D2C9029BF...가 래더 1 제출본과 같음. 코드는 탐색 없는 greedy (results/my_agent_greedy_v8.py에서 name만 바꿈, 2693바이트).
  - MokaS (래더 4에 낸 것과 같은 코드·가중치), v7 (E13a_60), P6.
- 시드 90000-90499 (처음 쓰는 번호대), 쌍마다 1000판, 기준 봇 없음, --workers 6.

```
python tools/course_ladder.py --entries results/entries_v6chk --out results/ladder --date v6chk_90000 --seeds 90000-90499 --baselines none --workers 6 | Tee-Object results/ladder_v6chk_90000.txt
```

- MokaS가 v6를 79.3%로 이김 (95% 범위 약 76.8 ~ 81.8%).
- 처음 보는 대역 P6 상대: v6 72.5% → v7 80.7% → MokaS 84.2%.
- v7이 v6를 63.4%로 이김. 실험 13(시드 20000번대)의 63.4%와 같은 숫자가 다른 시드에서 다시 나옴.
- 시간 초과: MokaS 4번 (3000판), 나머지 0번.

## 해석

- 실제 래더에서 결과가 있는 v6와 비교하면, 래더 4의 MokaS는 노트북 기준으로 v6를 약 4 : 1로 이기는 에이전트. 처음 보는 상대(P6)에게도 v6보다 11.7%p 높음.
- 래더 3에서 v6는 19명 중 10위 (학생 상대 47.4%). MokaS가 실제 학생 상대로 얼마나 오를지는 노트북 숫자로 바로 옮길 수 없음. "연습한 상대에게만 강해진다"는 일이 실험 11~15에서 반복됐기 때문. 래더 4에서 같은 학생들을 상대로 한 전적을 래더 3(v6)과 상대별로 비교해서 판단함.
- MokaS의 P6 상대는 84.2%로, 다른 시드에서 잰 86.4~87.2%보다 조금 낮음. P6 상대 승률은 시드 구간에 따라 2~3%p 움직임.
