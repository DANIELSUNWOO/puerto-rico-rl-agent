# 실험 6: 탐색 봇(SearchLite)과도 연습하기 (2026-11-09 ~ 11-10)

## 목적

- Moka의 가장 낮은 승률은 탐색형 상대 (Moka v2 기준 SearchLite 59.7%, Search 57.5%). 다른 학생들도 forward model로 앞을 보는 에이전트를 만들 수 있음.
- 탐색 봇과 직접 연습하면 탐색형 상대에게 강해지는지, 그 대가로 다른 상대에게 약해지지 않는지 확인.
- 실험 5가 대조군. 출발점, 학습량, 학습률, 체크포인트 간격이 같고 상대 구성만 다름.

## 설계

- 출발점: E4b_30 (Moka v2)
- 상대 구성: 자기 자신 20%, SearchLite 10%, 나머지는 실험 5와 같음 (원본 5%, E3_10 5%, E3_20 10%, E3_30 10%, TradeBuilding 15%, ActionValue 15%, Factory 5%, ShippingRush 5%)
- 실험 5와 다른 점: 자기 자신 30% → 20%, SearchLite 0% → 10%
- 학습률 0.00001(학습 끝에 0까지 줄어듦), 600만 스텝, 100만마다 체크포인트 (E6_10 ~ E6_60)

명령:

```
python training/train_moka.py --num_players 2 --init_ckpt results/exp04b_pastself/checkpoints/ckpt_final.pt --pool_ckpts e3_10=...,e3_20=...,e3_30=... --opponents self:0.2,searchlite:0.1,orig:0.05,e3_10:0.05,e3_20:0.1,e3_30:0.1,tradebuilding:0.15,actionvalue:0.15,factory:0.05,shippingrush:0.05 --lr 1e-5 --total_timesteps 6000000 --ckpt_interval 1000000 --eval_interval 1000000000 --out_dir results/exp06_searchlite
```

해석:

- 순위가 학습량 순서와 정확히 같음. 실험 3, 4에 이어 세 번째. 400만 → 600만에서도 계속 오름 (실험 5: 맞대결 68.0%, 실험 6: 55.8%). 아직 포화 아님.
- E5_20은 출발점과 50.0%로 같음. 200만까지는 거의 안 늘고 그 뒤에 늘었음. 학습 중 숫자에서도 100만 지점은 출발점과 비슷했음.
- 같은 학습량끼리 실험 6 vs 실험 5: 51.5%, 51.0%, 53.8%. 모두 흔들림 안. SearchLite를 섞어도 참가자끼리의 실력은 떨어지지 않았고, 오르지도 않았음.
- SearchLite 상대: 실험 5는 학습해도 그대로(62.5% → 57.5%), 실험 6은 200만에서 이미 78.8%, 600만에서 89.5%. 실험 6의 효과가 분명함.
- TradeBuilding, ActionValue 상대는 모두 97% 이상. 차이 없음.
- E4b_30의 SearchLite 125/200, TradeBuilding 198/200, ActionValue 198/200은 실험 4 최종 확인 B(같은 시드 10000번대)와 판 수까지 똑같음. 같은 시드 + 같은 에이전트면 결과가 같다는 것을 다시 확인.
- 리그전 시간 예상이 틀림. SearchLite 쌍이 1~3시간 걸릴 거라고 봤는데 쌍마다 약 25분. 학습 때는 SearchLite가 8판을 한 프로그램에서 번갈아 막았지만, 리그전은 작업자마다 따로 돌아서 그만큼 느리지 않음.

결론:

- Moka v3 후보: E6_60. 참가자끼리는 E5_60과 같은 실력(53.8%, 순위 승률 59.8% vs 61.3%)이고, SearchLite 상대는 89.5%로 E5_60(57.5%)보다 32%p 높음. "모든 상대에게 고르게 강한" 목표에 더 맞음.
- 남은 확인: SearchLite는 학습 상대였으므로, 학습에 쓰지 않은 Search, MCTS 상대도 올랐는지 최종 확인 B에서 확인.
